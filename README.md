# Spring Twin CLI

Spring Twin CLI --- инструмент анализа архитектуры Java / Spring Boot
проектов.

Он строит граф зависимостей между классами на основе:
- структурных зависимостей из байткода (.class)

Далее граф используется для кластеризации проекта и генерации задач для
AI агентов (Cursor AI, Kilo Code) для архитектурного рефакторинга.

------------------------------------------------------------------------

## Основные возможности

1.  **Анализ байткода**
	- Наследование класса или интерфейса
	- Имплементация интерфейса
	- Поле класса
	- Аргумент метода или конструктора
	- Возвращаемый тип метода
	- Использование в коде (статическая инициализация или тело метода): вызов метода, объявление переменной итд
	- Аннотации
2.  **Кластеризация архитектуры**
    -   выделение логических модулей проекта
    -   поиск межкластерных связей
3.  **Генерация задач для AI**
    -   задачи для рефакторинга
    -   уменьшение связности между кластерами
    -   разбиение крупных классов

------------------------------------------------------------------------

## Установка

Требования:

-   Java 21+
-   Gradle 8+

Сборка:

    ./gradlew build

Запуск CLI:

    java -jar spring-twin-cli.jar

------------------------------------------------------------------------

## Команды

### 1. Анализ байткода

    spring-twin scan-bytecode   --classes <path>   --output <bytecode.json>   --include <classMasks>   --exclude <classMasks> --merge-inner-classes <true|false>

Параметр `--classes`: для windows символы '\\' должны быть экранированы.
например: c:\\\\myproject\\\\build\\\\classes
 
Параметры `--include` и `--exclude`:
- маски полных имён классов (FQCN), например: `com.example.*`, `*.service.*`
- упрощённый синтаксис: `*` (любые символы), `?` (один символ)
- проверка по вхождению: достаточно указать часть пакета, например: `order`
- несколько масок перечисляются через `;`, например: `com.example.*;com.demo.*`

Параметр `--merge-inner-classes`: объединять вложенные классы с родительскими, по умолчанию true.

Результат: JSON граф зависимостей из байткода.

------------------------------------------------------------------------

### 2. Кластеризация

    spring-twin cluster  --deps <dependencies.json>   --output <clusters.json>

Результат: - список кластеров (логических модулей) - метрики качества
кластеризации - связи между кластерами.

------------------------------------------------------------------------

### 3. Генерация задач для AI

    spring-twin generate-refactoring   --clusters <clusters.json>   --output <tasks.json>

Результат: список задач для AI‑агентов по архитектурному рефакторингу.

------------------------------------------------------------------------

Spring Twin помогает LLM и разработчикам лучше понимать архитектуру
проекта и планировать безопасный рефакторинг.
