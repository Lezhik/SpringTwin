# 009-annotation-type-extractor — API

## Статус: complete

## Описание

Извлечение зависимостей по аннотациям класса, полей, методов и параметров методов из `.class` файла.

## Классы

### `spring.twin.scan.AnnotationTypeExtractor`

**Тип:** класс с внедрением через конструктор (Spring bean)

**Методы:**

- `Set<String> extract(byte[] classBytes)` — анализирует байткод класса и извлекает все типы аннотаций. Обходит: аннотации класса (`ClassNode.visibleAnnotations`, `ClassNode.invisibleAnnotations`), аннотации полей, аннотации методов, аннотации параметров методов. Возвращает множество FQCN. **Метод должен быть аннотирован Javadoc на английском языке.**

## Извлекаемые связи

- Аннотации класса (runtime visible и invisible)
- Аннотации полей
- Аннотации методов
- Аннотации параметров методов
- Типы из generic-сигнатур аннотаций (если применимо)

## Зависимости

- Фича 002: `FqcnNormalizer` — для конвертации внутренних имён аннотаций
- Фича 005: `GenericTypeExtractor` — для извлечения типов из сигнатур аннотаций
- Внешняя: `org.ow2.asm:asm-tree` — для парсинга байткода

## Результат

Создан класс `AnnotationTypeExtractor` с заглушками методов.
