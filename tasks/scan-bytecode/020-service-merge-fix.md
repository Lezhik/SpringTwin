# 020-service-merge — Исправление

## Статус: complete

## Описание

Запуск тестов и исправление ошибок для фичи service-merge.

## Инструкции

1. Запустить тесты: `gradlew.bat clean test --tests "spring.twin.scan.ScanBytecodeServiceTest"`
2. Если тесты не проходят — проанализировать сообщения об ошибках
3. Исправить реализацию `ScanBytecodeService` в соответствии с обнаруженными ошибками
4. Повторно запустить тесты
5. Убедиться, что все тесты проходят (зелёные), включая ранее существовавшие
6. Запустить полную сборку: `gradlew.bat clean build` — убедиться, что нет ошибок компиляции и все тесты проходят

## Типичные проблемы

- Ошибка компиляции — метод `build()` с 4 параметрами не найден в `DependencyGraphBuilder` (фича 019 не реализована)
- Ошибка компиляции — метод `mergeInnerClasses()` не найден в `ScanBytecodeParams` (фича 018 не реализована)
- Существующие тесты падают — мок `dependencyGraphBuilder.build()` настроен на 3 параметра, а вызывается с 4; нужно обновить моки
- `params.mergeInnerClasses()` возвращает неверное значение — проблема в `ScanBytecodeParams` (фича 018)
