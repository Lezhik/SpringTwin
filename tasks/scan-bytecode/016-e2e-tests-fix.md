# 016-e2e-tests — Исправление

## Статус: complete

## Описание

Запуск E2E тестов и исправление ошибок полного пайплайна scan-bytecode.

## Инструкции

1. Запустить все тесты: `gradlew.bat clean test`
2. Особое внимание к E2E тестам: `gradlew.bat clean test --tests "spring.twin.scan.e2e.ScanBytecodeE2eTest"`
3. Если тесты не проходят — проанализировать сообщения об ошибках
4. Исправить реализацию соответствующих компонентов в соответствии с обнаруженными ошибками
5. Повторно запустить тесты
6. Убедиться, что все тесты проходят (зелёные)
7. Запустить полную сборку: `gradlew.bat clean build` — убедиться, что нет ошибок компиляции и все тесты проходят

## Типичные проблемы

- Testee-классы не скомпилированы — нужно сначала запустить `gradlew.bat clean classes testClasses`
- Путь к testee-классам неверный — проверить `build/classes/java/test/spring/twin/testee/`
- Зависимости не обнаружены — проблема в одном из экстракторов (006-010)
- Generic-типы не извлечены — проблема в `GenericTypeExtractor`
- Массивы ссылаются на массив вместо базового типа — проблема в `FqcnNormalizer`
- Маски не работают — проблема в `MaskMatcher`
- JSON не отсортирован — проблема в `DependencyJsonWriter`
- Аннотации не обнаружены — проблема в `AnnotationTypeExtractor`
- Использование в коде не обнаружено — проблема в `CodeUsageExtractor`

## Отладка

Если E2E тесты падают, рекомендуется:
1. Запустить unit-тесты конкретного экстрактора для локализации проблемы
2. Проверить содержимое testee-классов — соответствуют ли они ожиданиям тестов
3. Временно добавить логирование в `BytecodeClassAnalyzer` для просмотра извлечённых зависимостей
