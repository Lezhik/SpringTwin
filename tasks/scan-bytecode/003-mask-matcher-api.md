# 003-mask-matcher — API

## Статус: pending

## Описание

Сопоставление FQCN с масками include/exclude. Поддерживает упрощённый синтаксис: `*` (любые символы), `?` (один символ), проверку по вхождению подстроки.

## Классы

### `spring.twin.scan.MaskMatcher`

**Тип:** утилитный класс (final, приватный конструктор)

**Методы:**

- `static boolean matchesAny(String fqcn, List<String> masks)` — проверяет, соответствует ли FQCN хотя бы одной маске из списка. Если список масок пуст — возвращает `true` (пустой include = любой класс, пустой exclude = не исключать). **Метод должен быть аннотирован Javadoc на английском языке.**

- `static boolean matches(String fqcn, String mask)` — проверяет, соответствует ли FQCN одной маске. Поддерживает: `*` → любые символы (включая пустые), `?` → ровно один символ, без спецсимволов — проверка вхождения подстроки (contains). **Метод должен быть аннотирован Javadoc на английском языке.**

- `static boolean shouldInclude(String fqcn, List<String> includeMasks, List<String> excludeMasks)` — комбинированная проверка: FQCN включается, если соответствует include (или include пустой) И НЕ соответствует exclude. **Метод должен быть аннотирован Javadoc на английском языке.**
