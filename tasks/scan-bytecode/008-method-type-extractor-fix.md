# 008-method-type-extractor — Исправление

## Статус: pending

## Описание

Запуск тестов и исправление ошибок для фичи method-type-extractor.

## Инструкции

1. Запустить тесты: `gradlew.bat clean test --tests "spring.twin.scan.MethodTypeExtractorTest"`
2. Если тесты не проходят — проанализировать сообщения об ошибках
3. Исправить реализацию `MethodTypeExtractor` в соответствии с обнаруженными ошибками
4. Повторно запустить тесты
5. Убедиться, что все тесты проходят (зелёные)
6. Запустить полную сборку: `gradlew.bat clean build` — убедиться, что нет ошибок компиляции и все тесты проходят

## Типичные проблемы

- Парсинг дескриптора метода некорректен — `Type.getArgumentTypes()` и `Type.getReturnType()` используются неправильно
- Примитивные возвращаемые типы не отфильтрованы — `FqcnNormalizer.fromDescriptor()` должен возвращать empty
- Массивы в параметрах не обработаны — базовый тип не извлечён
- Generic-сигнатура метода проигнорирована
- Конструктор не обработан — `<init>` пропущен или вызывает ошибку
- Дублирование типов из дескриптора и generic-сигнатуры
