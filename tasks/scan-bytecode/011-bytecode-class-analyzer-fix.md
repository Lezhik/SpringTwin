# 011-bytecode-class-analyzer — Исправление

## Статус: pending

## Описание

Запуск тестов и исправление ошибок для фичи bytecode-class-analyzer.

## Инструкции

1. Запустить тесты: `gradlew.bat clean test --tests "spring.twin.scan.BytecodeClassAnalyzerTest"`
2. Если тесты не проходят — проанализировать сообщения об ошибках
3. Исправить реализацию `BytecodeClassAnalyzer` в соответствии с обнаруженными ошибками
4. Повторно запустить тесты
5. Убедиться, что все тесты проходят (зелёные)
6. Запустить полную сборку: `gradlew.bat clean build` — убедиться, что нет ошибок компиляции и все тесты проходят

## Типичные проблемы

- Один из экстракторов не внедрён через конструктор
- Результаты экстракторов не объединены корректно
- `extractClassName` возвращает внутреннее имя вместо FQCN
- NullPointerException если один из экстракторов вернул null вместо пустого множества
- Дублирование не устранено — не используется Set
