# 017-inner-class-merger — Исправление

## Статус: complete

## Описание

Запуск тестов и исправление ошибок для фичи inner-class-merger.

## Инструкции

1. Запустить тесты: `gradlew.bat clean test --tests "spring.twin.scan.InnerClassMergerTest"`
2. Если тесты не проходят — проанализировать сообщения об ошибках
3. Исправить реализацию `InnerClassMerger` в соответствии с обнаруженными ошибками
4. Повторно запустить тесты
5. Убедиться, что все тесты проходят (зелёные)
6. Запустить полную сборку: `gradlew.bat clean build` — убедиться, что нет ошибок компиляции и все тесты проходят

## Типичные проблемы

- `UnsupportedOperationException` — заглушка не заменена на реализацию
- `NullPointerException` при передаче null в `isInnerClass()` или `getOuterClassName()` — не обработан null
- Некорректное определение внутреннего класса — `$` в начале строки не должен считаться признаком внутреннего класса
- Самоссылка после мержа — внешний класс содержит себя в зависимостях после объединения с внутренним
- Зависимости внутренних классов не перенесены в множество внешнего класса
- Ссылки на внутренние классы в значениях (зависимостях) не заменены на внешние классы
- Порядок ключей/значений не отсортирован — нужно использовать TreeMap/TreeSet
