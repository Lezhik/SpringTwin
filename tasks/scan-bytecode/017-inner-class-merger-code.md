# 017-inner-class-merger — Реализация

## Статус: complete

## Описание

Реализация `InnerClassMerger` — утилитного класса для объединения вложенных классов с родительскими.

## Классы и методы

### `spring.twin.scan.InnerClassMerger`

**Тип:** final утилитный класс

**Реализация:**

- Приватный конструктор — предотвращает инстанцирование

- `static boolean isInnerClass(String fqcn)` — возвращает `true`, если `fqcn` не null, не пустой и содержит символ `$`, при этом `$` не является первым символом. Иначе возвращает `false`. **Метод должен быть аннотирован Javadoc на английском языке.**

- `static String getOuterClassName(String fqcn)` — если `fqcn` не null и `isInnerClass(fqcn)` возвращает `true`, извлекает подстроку от начала до первого символа `$`. Иначе возвращает `fqcn` без изменений (включая null). **Метод должен быть аннотирован Javadoc на английском языке.**

- `static Map<String, Set<String>> mergeInnerClasses(Map<String, Set<String>> graph)` — алгоритм:
  1. Создать `TreeMap<String, TreeSet<String>>` для накопления результата
  2. Для каждого entry в исходном графе:
     - Если ключ — внутренний класс (`isInnerClass`), получить имя внешнего через `getOuterClassName`
     - Если внешний класс уже есть в результате, добавить все зависимости внутреннего класса в множество внешнего
     - Если внешнего класса нет в результате, создать новую запись с зависимостями внутреннего класса
     - Если ключ — не внутренний класс, добавить его в результат (создать TreeSet из его зависимостей)
  3. Для каждого множества зависимостей в результате: заменить все внутренние классы в значениях на их внешние классы, удалить самоссылки (где ключ равен значению после замены)
  4. Вернуть `LinkedHashMap` из TreeMap для детерминированного порядка
  **Метод должен быть аннотирован Javadoc на английском языке.**

- `static Map<String, Set<String>> mergeInnerClasses(Map<String, Set<String>> graph, boolean merge)` — если `merge == true`, делегирует к `mergeInnerClasses(graph)`. Если `merge == false`, возвращает исходный `graph` без изменений. **Метод должен быть аннотирован Javadoc на английском языке.**

## Логика работы

1. `isInnerClass()` — проверка наличия `$` в FQCN (не в начале), что по соглашению JVM означает внутренний класс
2. `getOuterClassName()` — извлечение имени top-level класса путём обрезки по первому `$`
3. `mergeInnerClasses(Map)` — проход по всем записям графа, перенесение зависимостей внутренних классов к внешним, удаление внутренних классов из ключей, замена ссылок на внутренние классы в значениях на внешние, удаление самоссылок
4. `mergeInnerClasses(Map, boolean)` — условный вызов мержа в зависимости от флага
