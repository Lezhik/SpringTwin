# 033-inner-class-merger-details — API

## Статус: pending

## Описание

Добавление метода объединения вложенных классов для детализированного графа в `InnerClassMerger`. Новый метод работает с `Map<String, Map<String, Set<LinkDetails>>>` вместо `Map<String, Set<String>>`.

## Классы

### `spring.twin.scan.InnerClassMerger` (модификация)

**Новые методы:**

- `static Map<String, Map<String, Set<LinkDetails>>> mergeInnerClassesDetails(Map<String, Map<String, Set<LinkDetails>>> graph, boolean merge)` — условно объединяет вложенные классы с родительскими в детализированном графе. Если merge=true, выполняет объединение; если false, возвращает граф без изменений. **Метод должен быть аннотирован Javadoc на английском языке.**

**Правила объединения:**

- Вложенный класс — FQCN содержит `$` (не первый символ)
- Родительский класс — часть FQCN до первого `$`
- При объединении:
  1. Записи вложенного класса (ключи) удаляются из внешней карты
  2. Зависимости вложенного класса добавляются к зависимостям родительского класса (внутренняя карта)
  3. Ссылки на вложенный класс в значениях других классов заменяются на родительский класс
  4. Самоссылки (родительский класс → родительский класс) удаляются
  5. LinkDetails при объединении сохраняются без изменений

**Существующие методы:**

- `static Map<String, Set<String>> mergeInnerClasses(Map<String, Set<String>> graph, boolean merge)` — остаётся без изменений
