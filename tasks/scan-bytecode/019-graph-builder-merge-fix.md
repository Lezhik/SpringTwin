# 019-graph-builder-merge — Исправление

## Статус: complete

## Описание

Запуск тестов и исправление ошибок для фичи graph-builder-merge.

## Инструкции

1. Запустить тесты: `gradlew.bat clean test --tests "spring.twin.scan.DependencyGraphBuilderTest"`
2. Если тесты не проходят — проанализировать сообщения об ошибках
3. Исправить реализацию `DependencyGraphBuilder` в соответствии с обнаруженными ошибками
4. Повторно запустить тесты
5. Убедиться, что все тесты проходят (зелёные), включая ранее существовавшие
6. Запустить полную сборку: `gradlew.bat clean build` — убедиться, что нет ошибок компиляции и все тесты проходят

## Типичные проблемы

- `InnerClassMerger` не найден — не добавлен import или класс не создан (фича 017)
- Новый метод `build()` не делегирует к существующему — дублирование логики построения графа
- Существующий метод `build()` изменён — нарушение обратной совместимости
- Результат мержа не отсортирован — `InnerClassMerger` должен возвращать отсортированные данные
- Внутренние классы не объединяются — `InnerClassMerger.mergeInnerClasses()` вызывается с неправильным флагом
