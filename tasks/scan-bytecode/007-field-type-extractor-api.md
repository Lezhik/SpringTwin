# 007-field-type-extractor — API

## Статус: pending

## Описание

Извлечение зависимостей по типам полей класса из `.class` файла. Обрабатывает обычные поля, массивы (ссылка на базовый тип) и generic-поля.

## Классы

### `spring.twin.scan.FieldTypeExtractor`

**Тип:** класс с внедрением через конструктор (Spring bean)

**Методы:**

- `Set<String> extract(byte[] classBytes)` — анализирует байткод класса и извлекает все типы полей. Для каждого поля извлекает тип из дескриптора, а также типы из generic-сигнатуры поля если она есть. Возвращает множество FQCN. **Метод должен быть аннотирован Javadoc на английском языке.**

## Извлекаемые связи

- Тип поля из дескриптора (`FieldNode.desc`)
- Типы из generic-сигнатуры поля (`FieldNode.signature`) через `GenericTypeExtractor`

## Зависимости

- Фича 002: `FqcnNormalizer` — для конвертации дескрипторов
- Фича 005: `GenericTypeExtractor` — для извлечения типов из generic-сигнатур
- Внешняя: `org.ow2.asm:asm-tree` — для парсинга байткода

## Результат

Создан класс `FieldTypeExtractor` с заглушками методов.
