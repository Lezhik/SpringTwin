# 023-link-type-enum — API

## Статус: complete

## Описание

Перечисление типов связей `LinkType` для классификации зависимостей между классами. Каждый тип связи определяет характер зависимости: наследование, поле, метод, аннотация и т.д.

## Классы

### `spring.twin.scan.LinkType`

**Тип:** enum

**Константы:**

- `SUPERCLASS` — базовый класс (extends), поле details пустое
- `INTERFACE` — имплементируемый интерфейс (implements), поле details пустое
- `FIELD` — поле класса, в поле details имя поля
- `STATIC_BLOCK` — использование в статическом блоке инициализации, поле details пустое
- `METHOD` — использование в методе (возвращаемый тип, аргумент или в коде метода), в поле details сигнатура метода
- `CLASS_ANNOTATION` — аннотация к классу, поле details пустое
- `FIELD_ANNOTATION` — аннотация к полю, в details имя поля
- `METHOD_ANNOTATION` — аннотация к методу, в details сигнатура метода
- `METHOD_ARG_ANNOTATION` — аннотация к аргументу метода, в details сигнатура метода

**Методы:**

- `String getJsonName()` — возвращает имя константы для сериализации в JSON. **Метод должен быть аннотирован Javadoc на английском языке.**

**Дополнительные требования:**

- Перегрузить `equals()` и `hashCode()` чтобы избежать дублирования одинаковых ссылок в `Set<LinkDetails>`
- Конструктор enum не принимает параметров, jsonName совпадает с именем константы
