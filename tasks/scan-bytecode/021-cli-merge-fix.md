# 021-cli-merge — Исправление

## Статус: complete

## Описание

Запуск тестов и исправление ошибок для фичи cli-merge.

## Инструкции

1. Запустить тесты: `gradlew.bat clean test --tests "spring.twin.command.ScanBytecodeCommandTest"`
2. Если тесты не проходят — проанализировать сообщения об ошибках
3. Исправить реализацию `ScanBytecodeCommand` в соответствии с обнаруженными ошибками
4. Повторно запустить тесты
5. Убедиться, что все тесты проходят (зелёные), включая ранее существовавшие
6. Запустить полную сборку: `gradlew.bat clean build` — убедиться, что нет ошибок компиляции и все тесты проходят

## Типичные проблемы

- Ошибка компиляции — сигнатура метода `scanBytecode()` изменилась, но не все вызовы обновлены
- Ошибка компиляции — `ScanBytecodeParams.of()` с 5 параметрами не найден (фича 018 не реализована)
- Существующие тесты падают — вызовы `scanBytecode()` в тестах используют 4 параметра вместо 5
- `Boolean.parseBoolean()` некорректно обрабатывает значение — проверить что defaultValue = "true" в `@ShellOption`
- `@ShellOption` не принимает `defaultValue` для boolean — возможно нужно использовать тип `String` вместо `boolean`
