# 022-e2e-merge-tests — Исправление

## Статус: pending

## Описание

Запуск тестов и исправление ошибок для E2E тестов опции `--merge-inner-classes`.

## Инструкции

1. Запустить тесты: `gradlew.bat clean test --tests "spring.twin.scan.e2e.ScanBytecodeE2eMergeTest"`
2. Если тесты не проходят — проанализировать сообщения об ошибках
3. Исправить тесты или реализацию в соответствии с обнаруженными ошибками
4. Повторно запустить тесты
5. Убедиться, что все тесты проходят (зелёные)
6. Запустить полную сборку: `gradlew.bat clean build` — убедиться, что нет ошибок компиляции и все тесты проходят, включая все предыдущие E2E тесты

## Типичные проблемы

- `Outer$Inner` не найден в графе при `mergeInnerClasses=false` — testee-класс `Outer` может не иметь зависимостей, которые попадают под маски; проверить что внутренний класс `Outer.Inner` компилируется и сканируется
- `Outer` не найден в графе при `mergeInnerClasses=true` — `InnerClassMerger` некорректно обрабатывает случай когда внешний класс отсутствует в графе
- Самоссылка после мержа — `InnerClassMerger` не удаляет самоссылки
- Зависимости на `Outer$Inner` не заменены на `Outer` — `InnerClassMerger` не обрабатывает значения (зависимости)
- Ошибка компиляции — `ScanBytecodeParams` не имеет 5-параметрового конструктора (фича 018 не реализована)
- Все предыдущие E2E тесты падают — нарушение обратной совместимости в пайплайне
