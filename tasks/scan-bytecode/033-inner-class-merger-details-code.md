# 033-inner-class-merger-details — Реализация

## Статус: pending

## Описание

Реализация метода `mergeInnerClassesDetails()` в `InnerClassMerger` для объединения вложенных классов в детализированном графе.

## Классы и методы

### `spring.twin.scan.InnerClassMerger` (модификация)

**Новый метод:**

- `static Map<String, Map<String, Set<LinkDetails>>> mergeInnerClassesDetails(Map<String, Map<String, Set<LinkDetails>>> graph, boolean merge)` — условно объединяет вложенные классы. **Метод должен быть аннотирован Javadoc на английском языке.**

**Реализация:**

1. Если `merge == false` → вернуть граф без изменений
2. Создать `TreeMap<String, Map<String, Set<LinkDetails>>>` для результата
3. Шаг 1 — обработка ключей (внешний уровень):
   - Для каждого ключа, который является вложенным классом (`isInnerClass(fqcn)`):
     - Получить родительский класс через `getOuterClassName(fqcn)`
     - Добавить зависимости вложенного класса к зависимостям родительского: объединить внутренние карты `Map<String, Set<LinkDetails>>`
     - Если родительского класса нет в графе — создать новую запись с зависимостями вложенного
   - Для ключей, не являющихся вложенными классами — скопировать как есть
4. Шаг 2 — замена ссылок на вложенные классы в значениях:
   - Для каждого класса в результате: проверить ключи внутренней карты
   - Если ключ внутренней карты — вложенный класс, заменить на родительский
   - Объединить Set<LinkDetails> при конфликте
5. Шаг 3 — удаление самоссылок:
   - Если внешний ключ совпадает с внутренним ключом — удалить запись
6. Вернуть отсортированный результат

## Логика работы

1. Проверить флаг merge
2. Объединить ключи-вложенные классы с родительскими
3. Заменить ссылки на вложенные классы в значениях
4. Удалить самоссылки
5. Вернуть отсортированный результат
