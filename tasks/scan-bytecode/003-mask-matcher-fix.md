# 003-mask-matcher — Исправление

## Статус: complete

## Описание

Запуск тестов и исправление ошибок для фичи mask-matcher.

## Инструкции

1. Запустить тесты: `gradlew.bat clean test --tests "spring.twin.scan.MaskMatcherTest"`
2. Если тесты не проходят — проанализировать сообщения об ошибках
3. Исправить реализацию `MaskMatcher` в соответствии с обнаруженными ошибками
4. Повторно запустить тесты
5. Убедиться, что все тесты проходят (зелёные)
6. Запустить полную сборку: `gradlew.bat clean build` — убедиться, что нет ошибок компиляции и все тесты проходят

## Типичные проблемы

- Неправильная конвертация маски в regex — не экранированы regex-метасимволы (`.`, `(`, `)` и т.д.)
- `*` не заменён на `.*` или заменён на `.*` без якорных привязок
- `?` не заменён на `.` или заменён с квантификатором
- Case-sensitivity — regex по умолчанию case-sensitive, но если используется `Pattern.CASE_INSENSITIVE`, тесты на регистр упадут
- Пустой список масок возвращает `false` вместо `true`
- `contains` вместо regex для простых масок работает некорректно
