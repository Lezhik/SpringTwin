# 004-class-file-scanner — Исправление

## Статус: completed

## Описание

Запуск тестов и исправление ошибок для фичи class-file-scanner.

## Инструкции

1. Запустить тесты: `gradlew.bat clean test --tests "spring.twin.scan.ClassFileScannerTest"`
2. Если тесты не проходят — проанализировать сообщения об ошибках
3. Исправить реализацию `ClassFileScanner` в соответствии с обнаруженными ошибками
4. Повторно запустить тесты
5. Убедиться, что все тесты проходят (зелёные)
6. Запустить полную сборку: `gradlew.bat clean build` — убедиться, что нет ошибок компиляции и все тесты проходят

## Типичные проблемы

- `NoSuchFileException` не обёрнут в `UncheckedIOException`
- `Files.walk()` не закрыт в try-with-resources — утечка файловых дескрипторов
- Разделители путей не заменены корректно на `.` (проблема на Windows с `\`)
- Расширение `.class` не удалено или удалено неправильно
- Пустая директория возвращает null вместо пустого списка
- Символ `$` во вложенных классах повреждён при обработке пути
