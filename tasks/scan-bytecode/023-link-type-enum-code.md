# 023-link-type-enum — Реализация

## Статус: complete

## Описание

Реализация enum `LinkType` для классификации типов связей между классами.

## Классы и методы

### `spring.twin.scan.LinkType`

**Тип:** enum

**Константы:**

- `SUPERCLASS` — базовый класс
- `INTERFACE` — имплементируемый интерфейс
- `FIELD` — поле класса
- `STATIC_BLOCK` — статический блок инициализации
- `METHOD` — метод (возвращаемый тип, аргумент, тело метода)
- `CLASS_ANNOTATION` — аннотация к классу
- `FIELD_ANNOTATION` — аннотация к полю
- `METHOD_ANNOTATION` — аннотация к методу
- `METHOD_ARG_ANNOTATION` — аннотация к аргументу метода

**Реализация:**

- `String getJsonName()` — возвращает `this.name()`. **Метод должен быть аннотирован Javadoc на английском языке.**

## Логика работы

1. Enum с 9 константами, представляющими типы связей согласно SPEC
2. Каждая константа имеет метод `getJsonName()`, возвращающий имя для JSON-сериализации
3. Имя для JSON совпадает с именем константы enum (например, `SUPERCLASS` → `"SUPERCLASS"`)
