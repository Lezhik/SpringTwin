# 035-e2e-details-tests — Исправление

## Статус: pending

## Описание

Запуск E2E тестов и исправление ошибок для полного пайплайна с детализированным форматом.

## Инструкции

1. Запустить тесты: `gradlew.bat clean test --tests "spring.twin.scan.e2e.ScanBytecodeE2eDetailsTest"`
2. Если тесты не проходят — проанализировать сообщения об ошибках
3. Определить, на каком уровне возникает ошибка (экстрактор, анализатор, builder, writer, merger)
4. Исправить соответствующий компонент
5. Повторно запустить E2E тесты
6. Убедиться, что все тесты проходят (зелёные)
7. Запустить полную сборку: `gradlew.bat clean build` — убедиться, что нет ошибок компиляции и ВСЕ тесты проходят (включая старые тесты 001-022)

## Типичные проблемы

- JSON не парсится — ошибка в сериализации LinkType/LinkDetails
- Отсутствуют некоторые LinkType — экстракторы не извлекают все типы связей
- Ключи не отсортированы — TreeMap не используется в writer
- Вложенные классы не объединяются — InnerClassMerger.mergeInnerClassesDetails() не вызывается
- NullPointerException — необработанные пустые значения
- Старые тесты падают — обратная совместимость нарушена при модификации существующих классов

## Важно

После исправления обязательно запустить ВСЕ тесты проекта: `gradlew.bat clean build` — чтобы убедиться, что изменения не сломали существующую функциональность.
