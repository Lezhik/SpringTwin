# 005-generic-type-extractor — Исправление

## Статус: complete

## Описание

Запуск тестов и исправление ошибок для фичи generic-type-extractor.

## Инструкции

1. Запустить тесты: `gradlew.bat clean test --tests "spring.twin.scan.GenericTypeExtractorTest"`
2. Если тесты не проходят — проанализировать сообщения об ошибках
3. Исправить реализацию `GenericTypeExtractor` в соответствии с обнаруженными ошибками
4. Повторно запустить тесты
5. Убедиться, что все тесты проходят (зелёные)
6. Запустить полную сборку: `gradlew.bat clean build` — убедиться, что нет ошибок компиляции и все тесты проходят

## Типичные проблемы

- Неправильный парсинг вложенных generic — не учтена глубина `<...>`
- Формальные параметры типа (`T:...`) ошибочно извлечены как типы
- Пропущены типы при wildcard (`+L...;`, `-L...;`)
- Неправильная обработка массивов внутри generic
- Не обработан `null` или пустая строка
- Типы из `L...;` не конвертированы через `FqcnNormalizer`
- Дублирование типов в результате (нужно использовать Set)
