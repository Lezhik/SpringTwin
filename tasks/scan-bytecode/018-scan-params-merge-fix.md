# 018-scan-params-merge — Исправление

## Статус: pending

## Описание

Запуск тестов и исправление ошибок для фичи scan-params-merge.

## Инструкции

1. Запустить тесты: `gradlew.bat clean test --tests "spring.twin.scan.ScanBytecodeParamsTest"`
2. Если тесты не проходят — проанализировать сообщения об ошибках
3. Исправить реализацию `ScanBytecodeParams` в соответствии с обнаруженными ошибками
4. Повторно запустить тесты
5. Убедиться, что все тесты проходят (зелёные), включая ранее существовавшие
6. Запустить полную сборку: `gradlew.bat clean build` — убедиться, что нет ошибок компиляции и все тесты проходят

## Типичные проблемы

- Ошибка компиляции в местах использования старого 4-параметрового конструктора — делегирующий конструктор не создан
- Ошибка компиляции в местах использования старого фабричного метода `of()` — делегирующий метод не создан
- `mergeInnerClasses()` возвращает `false` при использовании старого конструктора — не установлено значение по умолчанию `true`
- Record не позволяет иметь два конструктора с разным числом параметров — нужно использовать другой подход к обратной совместимости (статический фабричный метод вместо дополнительного конструктора)
