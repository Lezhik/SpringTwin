# 029-code-usage-extractor-details — Исправление

## Статус: pending

## Описание

Запуск тестов и исправление ошибок для фичи code-usage-extractor-details.

## Инструкции

1. Запустить тесты: `gradlew.bat clean test --tests "spring.twin.scan.CodeUsageExtractorDetailsTest"`
2. Если тесты не проходят — проанализировать сообщения об ошибках
3. Исправить реализацию `CodeUsageExtractor.extractDetails()` в соответствии с обнаруженными ошибками
4. Повторно запустить тесты
5. Убедиться, что все тесты проходят (зелёные)
6. Запустить полную сборку: `gradlew.bat clean build` — убедиться, что нет ошибок компиляции и все тесты проходят

## Типичные проблемы

- Статический блок `<clinit>` определяется как METHOD вместо STATIC_BLOCK
- Сигнатура метода формируется в неверном формате
- Имя класса в сигнатуре не конвертировано из внутреннего формата
- LinkType.STATIC_BLOCK передаётся с непустым details
- Дублирование LinkDetails в Set
