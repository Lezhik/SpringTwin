# 004-partition-model — Исправление

## Статус: pending

## Описание

Запуск тестов и исправление ошибок для фичи partition-model.

## Инструкции

1. Запустить тесты: `gradlew.bat clean test --tests "spring.twin.cluster.PartitionTest"`
2. Если тесты не проходят — проанализировать сообщения об ошибках
3. Исправить реализацию `Partition` в соответствии с обнаруженными ошибками
4. Повторно запустить тесты
5. Убедиться, что все тесты проходят (зелёные)
6. Запустить полную сборку: `gradlew.bat clean build` — убедиться, что нет ошибок компиляции и все тесты проходят

## Типичные проблемы

- `UnsupportedOperationException` — заглушка не заменена на реализацию
- `NullPointerException` — не обработан случай отсутствия узла в nodeCommunity
- copy не создаёт глубокую копию — изменения в копии влияют на оригинал
- communityCount не обновляется при moveNode в новое сообщество
- toCommunityMap возвращает модифицируемое представление — нужно возвращать независимую Map
