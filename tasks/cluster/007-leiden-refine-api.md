# 007-leiden-refine — API

## Статус: pending

## Описание

Фаза уточнения (refinement) алгоритма Лейдена. Проверяет стабильность сообществ, выявленных на фазе локального перемещения. Нестабильные сообщества разделяются на более мелкие. Сообщество считается нестабильным, если существуют узлы, для которых перемещение в отдельное сообщество увеличивает модулярность.

## Классы

### 1. `spring.twin.cluster.LeidenRefine`

**Тип:** @Component

**Конструктор:**
- `LeidenRefine()` — конструктор по умолчанию

**Методы:**
- `Partition refine(Map<String, Map<String, Double>> graph, Partition partition, double resolution, Random random)` — выполняет фазу уточнения. Для каждого сообщества: создаёт подграф из узлов сообщества, каждый узел изначально в своём подкластере, затем итеративно объединяет подкластеры если это увеличивает модулярность. Результат — новое разбиение с возможно большим числом сообществ. **Метод должен быть аннотирован Javadoc на английском языке.**
- `boolean isCommunityStable(int community, Map<String, Map<String, Double>> graph, Partition partition, double resolution)` — проверяет стабильность сообщества: ни один узел не может улучшить модулярность, переместившись в отдельное сообщество. **Метод должен быть аннотирован Javadoc на английском языке.**
