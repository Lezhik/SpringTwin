# 005-modularity-calculator — Исправление

## Статус: pending

## Описание

Запуск тестов и исправление ошибок для фичи modularity-calculator.

## Инструкции

1. Запустить тесты: `gradlew.bat clean test --tests "spring.twin.cluster.ModularityCalculatorTest"`
2. Если тесты не проходят — проанализировать сообщения об ошибках
3. Исправить реализацию `ModularityCalculator` в соответствии с обнаруженными ошибками
4. Повторно запустить тесты
5. Убедиться, что все тесты проходят (зелёные)
6. Запустить полную сборку: `gradlew.bat clean build` — убедиться, что нет ошибок компиляции и все тесты проходят

## Типичные проблемы

- `UnsupportedOperationException` — заглушка не заменена на реализацию
- Некорректная формула модулярности — ошибка в коэффициентах или знаках
- Двойной учёт рёбер — edgesInsideCommunity учитывает каждое ребро дважды
- Деление на ноль — пустой граф (2m = 0) не обработан
- Проблемы с точностью double — использовать `assertEquals(expected, actual, 0.001)`
- Некорректный ΔQ — не учтён вклад текущего сообщества узла
