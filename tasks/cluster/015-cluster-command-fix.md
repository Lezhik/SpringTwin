# 015-cluster-command — Исправление ошибок

## Статус: complete

## Описание

Запуск тестов и исправление ошибок для CLI команды `cluster`.

## Шаги

1. Запустить тесты: `gradlew.bat clean test --tests "spring.twin.command.ClusterCommandTest"`
2. Проанализировать падения тестов
3. Типичные проблемы:
   - Некорректный парсинг параметра `--resolution` из строки в Double
   - Несовпадение сообщения об успехе с ожидаемым в тестах
   - Ошибки в аннотациях `@ShellMethod` / `@ShellOption`
   - Некорректная обработка исключений от ClusterService
4. Исправить найденные ошибки
5. Повторно запустить тесты до полного прохождения
