# 007-leiden-refine — Исправление

## Статус: pending

## Описание

Запуск тестов и исправление ошибок для фичи leiden-refine.

## Инструкции

1. Запустить тесты: `gradlew.bat clean test --tests "spring.twin.cluster.LeidenRefineTest"`
2. Если тесты не проходят — проанализировать сообщения об ошибках
3. Исправить реализацию `LeidenRefine` в соответствии с обнаруженными ошибками
4. Повторно запустить тесты
5. Убедиться, что все тесты проходят (зелёные)
6. Запустить полную сборку: `gradlew.bat clean build` — убедиться, что нет ошибок компиляции и все тесты проходят

## Типичные проблемы

- `UnsupportedOperationException` — заглушка не заменена на реализацию
- Некорректный подграф — рёбра между узлами сообщества не все включены
- Конфликт номеров сообществ — новые подкластеры получают пересекающиеся номера с существующими
- Узлы теряются — не все узлы включены в результат
- isCommunityStable возвращает неверный результат — ошибка в вычислении ΔQ для нового сообщества
