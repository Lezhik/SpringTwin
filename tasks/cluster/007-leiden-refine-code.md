# 007-leiden-refine — Реализация

## Статус: pending

## Описание

Реализация `LeidenRefine`.

## Классы и методы

### `spring.twin.cluster.LeidenRefine`

**Тип:** @Component

**Реализация:**
- `LeidenRefine()` — конструктор по умолчанию
- `boolean isCommunityStable(int community, Map<String, Map<String, Double>> graph, Partition partition, double resolution)` — для каждого узла в сообществе вычисляет ΔQ при перемещении в новое пустое сообщество. Если хотя бы для одного узла ΔQ > 0, сообщество нестабильно. **Метод должен быть аннотирован Javadoc на английском языке.**
- `Partition refine(Map<String, Map<String, Double>> graph, Partition partition, double resolution, Random random)` — для каждого сообщества из partition: (1) получает узлы сообщества, (2) создаёт подграф содержащий только рёбра между узлами данного сообщества, (3) создаёт вспомогательное разбиение где каждый узел в своём подкластере, (4) выполняет локальное перемещение на подграфе (аналогично LeidenLocalMove но только внутри сообщества), (5) если подкластеров больше одного, назначает новые номера сообществ. Возвращает обновлённое разбиение. **Метод должен быть аннотирован Javadoc на английском языке.**

## Логика работы

1. `isCommunityStable()` — проверяет, может ли какой-либо узел улучшить модулярность, покинув сообщество
2. `refine()` — для каждого сообщества выполняет внутреннюю кластеризацию, разделяя нестабильные сообщества
