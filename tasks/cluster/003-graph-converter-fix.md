# 003-graph-converter — Исправление

## Статус: complete

## Описание

Запуск тестов и исправление ошибок для фичи graph-converter.

## Инструкции

1. Запустить тесты: `gradlew.bat clean test --tests "spring.twin.cluster.GraphConverterTest"`
2. Если тесты не проходят — проанализировать сообщения об ошибках
3. Исправить реализацию `GraphConverter` в соответствии с обнаруженными ошибками
4. Повторно запустить тесты
5. Убедиться, что все тесты проходят (зелёные)
6. Запустить полную сборку: `gradlew.bat clean build` — убедиться, что нет ошибок компиляции и все тесты проходят

## Типичные проблемы

- `UnsupportedOperationException` — заглушка не заменена на реализацию
- Несимметричный граф — забыли добавить обратное ребро при конвертации
- Двойной учёт веса рёбер — при подсчёте totalEdgeWeight каждое ребро учитывается дважды
- Петли не отфильтрованы — self-reference создаёт ребро A↔A
- Узлы-цели не включены в collectNodes — учтены только ключи внешней Map
