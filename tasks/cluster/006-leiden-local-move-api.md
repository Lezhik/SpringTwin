# 006-leiden-local-move — API

## Статус: pending

## Описание

Фаза локального перемещения алгоритма Лейдена. Узлы перемещаются между сообществами для максимизации модулярности. Процесс повторяется до стабилизации (ни один узел не перемещён за проход).

## Классы

### 1. `spring.twin.cluster.LeidenLocalMove`

**Тип:** @Component

**Конструктор:**
- `LeidenLocalMove()` — конструктор по умолчанию

**Методы:**
- `Partition move(Map<String, Map<String, Double>> graph, Partition partition, double resolution, Random random)` — выполняет фазу локального перемещения. Узлы перебираются в случайном порядке. Для каждого узла вычисляется прирост модулярности при перемещении в каждое соседнее сообщество. Узел перемещается в сообщество с максимальным положительным приростом. Процесс повторяется пока хотя бы один узел перемещается. Возвращает обновлённое разбиение. **Метод должен быть аннотирован Javadoc на английском языке.**
- `Set<Integer> neighborCommunities(String node, Map<String, Map<String, Double>> graph, Partition partition)` — возвращает множество сообществ, соседних с узлом (сообщества, в которых есть хотя бы один сосед узла). **Метод должен быть аннотирован Javadoc на английском языке.**
