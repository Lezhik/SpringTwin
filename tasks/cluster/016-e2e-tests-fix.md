# 016-e2e-tests — Исправление ошибок

## Статус: pending

## Описание

Запуск E2E тестов и исправление ошибок для команды `cluster`.

## Шаги

1. Запустить все тесты: `gradlew.bat clean test`
2. Запустить E2E тесты отдельно: `gradlew.bat clean test --tests "spring.twin.cluster.e2e.ClusterE2eTest"`
3. Проанализировать падения тестов
4. Типичные проблемы:
   - Выходной JSON не соответствует ожидаемой структуре (отсутствующие поля, неверные типы)
   - Некорректные значения cohesion/coupling (выход за пределы 0.0-1.0)
   - Penalty edges не обнаружены или обнаружены ложно
   - Алгоритм кластеризации не сходится или даёт нестабильные результаты
   - Проблемы с путями к файлам на Windows (экранирование разделителей)
   - Ошибки сериализации/десериализации JSON через Jackson
   - Несовпадение формата id кластеров (ожидается `cluster-N`)
   - Пустой входной файл вызывает NullPointerException вместо корректной обработки
5. Исправить найденные ошибки в соответствующих классах
6. Повторно запустить все тесты до полного прохождения: `gradlew.bat clean test`
7. Убедиться что все unit тесты и E2E тесты проходят одновременно
